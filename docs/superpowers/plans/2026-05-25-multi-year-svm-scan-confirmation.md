# Multi-Year SVM Scan and Confirmation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Retrain the final DINOv2 SVM, scan BC coast candidates for 2023-2025, and generate a multi-year temporal confirmation review page grouped by 0.01° coordinates.

**Architecture:** Keep training and scanning in the existing scripts, and add one focused post-processing script that merges candidate manifests from multiple years. The new script will group candidates by rounded lat/lon, emit a combined manifest plus summary JSON, and render a static review page with side-by-side year comparisons and localStorage-backed labels.

**Tech Stack:** Python 3.11+, torch, scikit-learn, PIL, static HTML/JS, existing Earth Engine pipeline.
